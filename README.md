# Under the Bed

Under the Bed is a dark, atmospheric 2D game made with Godot for Jame Game.

## About
Explore the game, face enemies, and experience a dark atmosphere inspired by the fear of what might be hiding under your bed.

## Built With
- Godot Engine
- GDScript

## How to Run
1. Download or clone this repository.
2. Open Godot Engine.
3. Import the project by selecting the `project.godot` file.
4. Run the project from the Godot editor.
